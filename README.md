## 运行

章节目录名含中文，Go 不允许这种 import path，所以**不能**用 `go run ./basic/01.变量定义`
或 `go build ./...`。进目录单独跑：

```bash
cd basic/01.变量定义
go run 变量定义.go
```

`go test` 同理，在 `basic/17.unit_test/` 里执行。

全部依赖在根目录的 `go.mod`，gin 章节开始时会追加 `go.sum`。
