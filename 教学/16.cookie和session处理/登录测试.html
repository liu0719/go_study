Cookie / Session 动手实验台

怎么看原理：点每个按钮的同时打开浏览器 F12 → Network，观察 Request Headers 里的 Cookie: 和 Response Headers 里的 set-cookie:。
重点看四个属性：点「写入 Cookie」后，把 Response 里的整条 set-cookie 抄下来读一遍 —— Path / Expires / HttpOnly / SameSite 每一个都是考点，而且它们决定这个 Cookie "什么时候、往哪儿、谁能读"。
为什么必须用浏览器点：Cookie 是浏览器自己携带的，curl 不带 -b/-c 参数就永远测不出登录态。

方案 A：裸 Cookie

把用户 ID 明文塞进 Cookie。先跑通 Set-Cookie 机制，生产环境不要用 —— 客户端可读写，随便改。
